asset_get_type

This function gets the type of asset being referenced from its name or handle.

One of the constants listed below will be returned.

 

Syntax:

asset_get_type(name_or_ref);

Argument Type Description
name_or_ref Asset or String The name of or a reference to the game asset to get the type of.

 

Returns:

Asset Type Constant

 

 

Example:

var _path_name = "pth_Path_" + string(global.Game); if (asset_get_type(_path_name) != asset_path) {     show_debug_message("Path " + _path_name + " doesn't exist!!!"); } else {     path_index = asset_get_index(_path_name); }

The above code picks an asset (in this case a path) dynamically based on the value of a global variable. If a path with that name does not exist, a debug message is shown. If the path does exist, it is assigned as the path_index of the instance.
